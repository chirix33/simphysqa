\paragraph{Iterative schema development.}
The schema was developed through successive creation, enrichment, and
revision of the simulator record representation. Project researchers will
review the resulting schema for field completeness, units, coordinate
frames, event definitions, and public/private information boundaries.
This human schema review is distinct from the sampled annotation audit
in Section~\ref{sec:human-annotation-audit}, which assesses populated
records produced using the schema.
